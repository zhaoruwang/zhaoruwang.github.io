# 赵汝望个人专业主页

这是一个无构建依赖的静态站点，核心叙事是“把复杂业务做成真正跑起来的增长系统”。

## 本地预览

```bash
cd /Users/zrw/Documents/公司/个人网站
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 文件

- `index.html`：页面内容和语义结构。
- `styles.css`：视觉系统、响应式布局和动效。
- `script.js`：导航、滚动揭示和轻量交互。
- `SITES.md`：交给 Sites 发布时的说明。

页面不依赖外部字体、图片或第三方 JavaScript，离线也能运行。
